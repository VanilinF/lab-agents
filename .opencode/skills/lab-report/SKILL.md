# Оформление отчёта по лабораторной

## Структура файла
Файл: docs/reports/lab-<номер>.md

Разделы строго в таком порядке:
1. Цель работы — одно-два предложения
2. Задание — что требовалось сделать
3. Ход работы — пронумерованные шаги, у каждого: команда в блоке кода + краткий комментарий
4. Результаты — что получилось, ссылки на скриншоты
5. Выводы — 3–5 пунктов

## Правила
- Язык — русский
- Скриншоты хранить в docs/reports/img/, подключать как ![описание](img/файл.png)
- Команды — в блоках ```bash
- Не выдумывать результаты: если чего-то нет в проекте — спросить пользователя
