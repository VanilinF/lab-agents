# Лабораторная работа №1. Настройка opencode, MCP и skills

## Цель работы

Настроить opencode для работы с ИИ-агентом: подключить MCP-серверы, создать skill для оформления отчётов и описать правила проекта.

## Задание

1. Установить и настроить opencode.
2. Подключить MCP-серверы context7 и filesystem.
3. Создать skill для оформления отчётов по лабораторным работам.
4. Описать правила работы агента в `AGENTS.md`.
5. Проверить работу MCP-серверов и skill.

## Ход работы

1. Проверка установленной версии opencode:

```bash
opencode --version
```

2. Создание конфигурации `opencode.json` с двумя MCP-серверами: удалённым context7 и локальным filesystem, ограниченным каталогом проекта:

```bash
cat opencode.json
```

В конфигурации подключены:

- `context7` — удалённый MCP-сервер (`https://mcp.context7.com/mcp`) для получения актуальной документации по библиотекам;
- `filesystem` — локальный MCP-сервер (`@modelcontextprotocol/server-filesystem`) с доступом к `/home/vanilinf/univer_work/lab-agents`.

3. Создание skill `lab-report` в каталоге `.opencode/skills/lab-report/`:

```bash
mkdir -p .opencode/skills/lab-report docs/reports
```

В `SKILL.md` описаны структура отчёта, требования к разделам, правила оформления скриншотов и запрет на выдумывание результатов.

4. Создание файла `AGENTS.md` с правилами проекта: язык ответов, стек, требования к коду, работа с секретами, использование context7 и skill `lab-report`.

5. Проверка подключения MCP context7 — выполнен запрос на разрешение библиотеки Django:

```text
/django/django
```

Сервер вернул список библиотек и доступные версии, включая Django 5.x.

6. Проверка MCP filesystem — запрошен список разрешённых каталогов и дерево проекта:

```bash
git ls-files
```

Сервер подтвердил доступ к каталогу проекта и вернул его структуру.

7. Проверка регистрации skill — skill `lab-report` успешно загружен агентом и использован при подготовке настоящего отчёта.

8. Фиксация результатов в git:

```bash
git log --oneline
```

```text
5b2b631 Add AGENTS.md with project rules
54217f2 Add lab-report skill
edfca52 Add opencode config with MCP servers (context7, filesystem)
```

## Результаты

В проекте настроены и проверены:

- конфигурация opencode с MCP-серверами context7 и filesystem — `opencode.json`;
- skill для оформления отчётов — `.opencode/skills/lab-report/SKILL.md`;
- правила проекта для агента — `AGENTS.md`.

MCP filesystem работает и предоставляет доступ к файлам проекта. MCP context7 выполняет разрешение библиотек; при проверке запрос документации по Django завершился таймаутом, что требует повторной проверки стабильности соединения.

Скриншоты в проекте отсутствуют. Для добавления их следует сохранить в `docs/reports/img/` и подключить в этом разделе в виде `![описание](img/файл.png)`.
